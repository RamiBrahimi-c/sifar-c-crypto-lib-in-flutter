# Contributing

Thanks for your interest.

**The C code in this project is author-maintained.** No pull requests
against `src/` — every change to the C library goes through the author
alone. This is a personal project and the code stays narrow on purpose.

**The Flutter side is more flexible.** PRs against the Dart wrappers
(`lib/`) or the Flutter UI (`example/lib/`) may be considered, especially
for bug fixes or small improvements. Please open an issue first to
discuss before writing code.

## What *is* welcome

- **Bug reports** — if something breaks, please open an issue with
  steps to reproduce.
- **Feature requests** — open an issue describing what you'd want
  and why.
- **Questions** — open an issue.

## What is not welcome

- Pull requests against the C source (`src/`)
- Unsolicited rewrites or refactors
- "I fixed X" PRs without prior discussion

If you want to use the library differently than it's provided, **fork it.**
That's what forks are for, and it's completely fine.
